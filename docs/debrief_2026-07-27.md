## What shipped

### 1. The connector bridge — reach became record
`b431530`. MCP connectors could be reached and nothing they returned could be
kept: the wall regenerates a number by re-running its artifact, and no model may
enter that path, so a connector call was unverifiable and pasting its value into
a script hit the hardcoded-constant tripwire.

The fix needed **zero changes to `verification.py`**: MCP is an open protocol, so
the same server named in the same config is callable by deterministic Python.
The artifact records the **call, never the answer**, so a re-run re-asks the
service. Reference connector: PubChem, no API key.

**R-MCP-2 is the load-bearing ruling** — some MCP servers *are* language models,
so a connector may back a claim only when its config declares
`"_verifiable": true`. Without that gate a config edit alone would silently put a
model inside verification.

*Live: caffeine MW 194.19 reproduced at rel_error 0.0; a supervised run finished
8/8 verified with three connector-derived claims.*

## How this moves the vision

**A design can now be measured.** The prompt already said "the thing is the
deliverable" with nothing behind it but matplotlib. A geometry kernel yields
volume, mass closure, interference — numbers the wall re-runs. Design stops being
an assertion.

**External knowledge can be kept.** Connector, AlphaFold DB and the four
biological databases all produce numbers that reproduce, where before they could
only ever be caveats.

**Hardware stopped being the ceiling** — and the shape is right: the expensive
non-reproducible step runs once as an *input*, findings derived from it verify
locally in milliseconds.

**Ideation stopped being capped at ten instruments**, which was silently
narrowing what the system would even consider.

**And knowledge now compounds.** Runbooks mean today's expensive failures are
paid for once.
