Variable inductor

* measure current through inductor
vm lll 0 dc 0
* voltage on inductor
V1 l2 0 { Vi }

L3 33 331 { Ll }
* measure current through inductor
vm33 331 0 dc 0

V3 33 0 { Vi }

F21 int21 0 B21 -1

B21 n1 n2 V = '( i ( Vm21 ) < { It } ? { Ll } : { Lh }) ' * v ( int21 )
* measure current through inductor
vm21 n2 0 dc 0
V21 n1 0 { Vi }
. control
unset askquit

. endc
. end
