This file exhibits many of the most important properties common to all SPICE circuit
description files including the following:
• The first line of the file is always interpreted as the title of the circuit. The title
may consist of any text string.
• Lines that provide user comments, but no circuit information, are begun by an
asterisk.
• A circuit device is specified by a device name, followed by the node(s) to which it
is connected, and then by any required parameter information.
• The first character of a device name tells the simulator what kind of device it is
(e.g. R = resistor, C = capacitor, E = voltage controlled voltage source).
