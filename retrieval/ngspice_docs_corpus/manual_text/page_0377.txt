17.5.2 Alias: Create an alias for a command
General Form:
alias [ word ] [ text ...]
Causes word to be aliased to text. History substitutions may be used, as in C-shell
aliases.
17.5.3 Alter*: Change a device or model parameter
Alter changes the value for a device or a specified parameter of a device or model.
General Form:
alter dev = < expression >
alter dev param = < expression >
alter @dev [ param ] = < expression >
<expression> must be real (complex isn't handled right now, integer is fine though, but
no strings. For booleans, use 0/1).
