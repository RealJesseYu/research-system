17.5. COMMANDS 423
The command prints system information useful for sending bug report to developers.
Information consists of
• Name of the operating system,
• CPU type,
• Number of physical processors,
• Number of logical processors,
• Total amount of DRAM available,
• DRAM currently available.
The example below shows the use of this command.
ngspice 1 -> sysinfo
OS : CYGWIN_NT -5.1 1 . 5 . 2 5 ( 0 . 1 5 6 / 4 / 2 ) 2008 -06 -12 19:34
CPU : Intel ( R ) Pentium ( R ) 4 CPU 3.40 GHz
