spice :: spicetoblt a1 a1
spice :: spicetoblt b1 b1

after 100 bltupdate }

20.6 Compiling
20.6.1 Linux
Get tcl8.4 from your distribution. You will need the blt plotting package (compatible to
the old tcl 8.4 only) from here. See also the actual blt wiki .
./configure --with-tcl ..
make
sudo make install
