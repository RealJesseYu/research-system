28.7.1.2 Macro arguments for vector ports and parameters
When a port or parameter has been defined as a vector in the interface specification, some
macros require an argument that includes the vector index, as in OUTPUT(y[i]), while
others accept only the simple port or parameter name. The first kind are identified as
"indexed" in the descriptions below. The index may be any C expression that specifies a
valid index for the vector.
