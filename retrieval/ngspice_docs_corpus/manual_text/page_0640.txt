30.9.3 EXAMPLES
Set the type of material #1 to silicon, then adjust the values of the temperature-dependent
bandgap model parameters:
material num =1 silicon eg =1.12 deg . dt =4.7 e -4 eg . tref =640.0
The recombination lifetimes can be set to extremely short values to simulate imperfect
semiconductor material:
material num =2 silicon tn =1 ps tp =1 ps
