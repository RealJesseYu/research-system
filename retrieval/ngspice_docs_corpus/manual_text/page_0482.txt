The next two structures are used by the callback function SendData (see 19.3.3.4). Each
time a new data point (e.g. time value and simulation output value(s)) is added to
the vector structure of the current plot, the function SendData is called by ngspice,
among its parameters the actual pointer pvecvaluesall, which contains an array of pointers
to pvecvalues, one for each vector. Logic return values are of type NG_BOOL, which is
typedefed to int.
