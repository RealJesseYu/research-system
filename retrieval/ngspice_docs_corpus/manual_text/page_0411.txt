17.5.68 Save*: Save a set of outputs
General Form:
save [ all | outvec ...]
Save a set of outputs, discarding the rest (if keyword all is not given). May be used to
dramatically reduce memory (RAM) requirements if only a few useful node voltages or
branch currents are saved.
Node voltages may be saved by giving the nodename or v(nodename). Currents through
an independent voltage source are given by i(sourcename) or sourcename# branch. Internal
