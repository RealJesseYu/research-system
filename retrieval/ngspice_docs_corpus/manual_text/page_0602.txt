It is not certain that a future call will be made with TIME exactly equal to the function
argument, but there will be a close match. Arithmetic rounding may occur and the
simulator may make only one call when requests are very closely spaced. The closeness
depends on the minimum timestep of the simulation.
cm_event_queue() is similar to cm_analog_set_perm_bkpt(), but functions with event-
driven models. When invoked, this function causes the model to be queued for calling
at the specified time, with CALL_TYPE == EVENT. There is no combining of closly-
spaced events. All other details applicable to cm_analog_set_perm_bkpt() apply to this
function as well.
