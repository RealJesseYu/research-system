16.14.4 Controls and commands
16.14.4.1 .lib
The ngspice .lib command (see 2.8) requires two parameters, a file name followed by a
library name. If no library name is given, the line
.lib filename
should be replaced by
.inc filename
Alternatively, the compatibility mode ( 16.14.1) may be set to 'ps'.
