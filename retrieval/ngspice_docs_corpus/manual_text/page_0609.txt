28.8.2.10 Function udn_XXX_ipc_val
Use STRUCT_PTR to access the value of the node data. Assign to IPC_V AL a bi-
nary representation of the data. Typically this can be accomplished by simply assigning
STRUCT_PTR to IPC_V AL.
Assign to IPC_V AL_SIZE an integer representing the size of the binary data in bytes.
