The .ALTER command is not available in ngspice. However, a new option in ngspice to
the altermod command ( 17.5.4) enables the simulation of design corners. The #Alter#
section in inv.cfg gives details. Specific to ngspice, again several .control section are
used.
# ALTER #
.control
* gate oxide thickness varied
altermod nm pm file [b3.min b3.typ b3.max]
.endc
.control
* power supply variation
alter vdd=[2.0 2.1 2.2]
.endc
.control
run
.endc
