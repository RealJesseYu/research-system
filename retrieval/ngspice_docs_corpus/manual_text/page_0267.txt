In addition, asynchronous set and reset signals exist, and each of the three methods of
changing the stored output of the d_srff have separate load values and delays associated
with them. You may also specify separate rise and fall delay values that are added to
those specified for the input lines; these allow for more faithful reproduction of the output
characteristics of different IC fabrication technologies.
Note that any UNKNOWN inputs other than s and r immediately cause the output to
go UNKNOWN.
