18.6. OUTPUT-TO-FILE OPTIONS 469
Example usage:
eprvcd 1 2 3 4 5 6 7 8 s0 s1 s2 s3 c3 > adder_x . vcd
Values for analog nodes and expressions (as for plot ) may be included, but expressions
may not contain spaces. Option "-t" sets the VCD file's time unit; values are rounded to
a negative power of 10. If not used the unit is chosen to fit the simulation's maximum
timestep. Analog values are examined only when an XSPICE event values changes unless
option "-a" is used to dump them at each timestep.
The file addr_x.vcd may be displayed by the following .control section (gtkwave has to
be installed):

18.6.2.1 Rawfile
This is the traditional spice-compatible output file for simulation data. It will be generated
during simulation if ngspice is started in batch mode ( 16.4.1) like
ngspice -b -r mysim.raw -o mysim.log myinput.cir
