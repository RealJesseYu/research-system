Description: The Piece-Wise Linear Controlled Source is a single input, single output
function similar to the Gain Block. However, the output of the PWL Source is
not necessarily linear for all values of input. Instead, it follows an I/O relationship
specified by you via the x_array and y_array coordinates. This is detailed below.
The x_array and y_array values represent vectors of coordinate points on the x
and y axes, respectively. The x_array values are progressively increasing input co-
ordinate points, and the associated y_array values represent the outputs at those
points. There may be as few as two ( x_array[n], y_array[n]) pairs specified, or
as many as memory and simulation speed allow. This permits you to very finely
approximate a non-linear function by capturing multiple input-output coordinate
points.
