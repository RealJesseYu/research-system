30.13.3 Examples
Normally, a 'numos' device model is used for MOSFET devices. However, it can be
changed into a bipolar-with-substrate-contact model, by specifying a bipolar structure
using the other cards, and indicating the device-structure type as shown here. The default
length is set to 1.0 µm so that when mask area is specified on the element line it can be
divided by this default to obtain the device width.
options bipolar defl =1.0
Specify that a 1D BJT has base area 1/10th that of the emitter, has an effective depth
of 0.2 µm and a length between the internal and external base contacts
options base . area =0.1 base . depth =0.2 base . len =1.5
If a circuit contains two instances of a bipolar transistor model named 'q1' and 'q2', the
following line tells the simulator to look for initial conditions in the 'OP1.q2', respectively.
