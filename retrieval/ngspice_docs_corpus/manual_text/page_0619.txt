An array (vector) parameter was expected on the .model card, but enclosing [ ] characters
were not found to delimit its values.
ERROR - model: %s - Unexpected end of model card
The end of the indicated .model line was reached before all required information was
supplied.
ERROR - model: %s - Array parameter must have at least one value

ERROR - model: %s - Bad real value

delimiters.
29.3 Code Model Error Messages
The following is a list of error messages that may be encountered while attempting to run
a simulation with certain code models. These are listed alphabetically based on the name
of the code model, and explanations follow the name and listing.
29.3.1 Code Model aswitch
cntl_error:
*****ERROR*****
ASWITCH: CONTROL voltage delta less than 1.0e-12
This message occurs as a result of the cntl_off and cntl_on values being less than 1.0e-12
volts/amperes apart.
