5.1.2 Special B-Source Variables time, temper, hertz
The special variables time and temper are available in a transient analysis, reflecting the
actual simulation time and circuit temperature. temper returns the circuit temperature,
given in degree C (see 2.12). The variable hertz is available in an AC analysis. time
is zero in the AC analysis, hertz is zero during transient analysis. Using the variable
hertz may cost some CPU time if you have a large circuit, because for each frequency
the operating point has to be determined before calculating the AC response.
5.1.3 par( 'expression ')
The B source syntax may also be used in output lines like .plot as algebraic expressions
for output (see Chapt. 15.6.6 ).
5.1.4 Piecewise Linear Function: pwl
Both B source types may contain a piece-wise linear dependency of one network variable:
Example: pwl_current
Bdio 1 0 I = pwl ( v ( A ) , 0 ,0 , 33 ,10 m , 100 ,33 m , 200 ,50 m )
v(A) is the independent variable x. Each pair of values following describes the x,y func-
tional relation: In this example at node A voltage of 0V the current of 0A is generated -
next pair gives 10mA flowing from ground to node 1 at 33V on node A and so forth.
