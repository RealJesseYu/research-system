17.5.103 Wrdata: Write data to a file (simple table)
General Form:
< set wr_singlescale >
< set wr_vecnames >
< option numdgt =7 >
...
wrdata [ file ] [ vecs ]
Writes out the vectors to file.
This is a very simple printout of data in array form. Variables are written in pairs: scale
vector, value vector. If variable is complex, a triple is printed (scale, real, imag). If more
than one vector is given, the third column again is the default scale, the fourth the data
of the second vector. The default format is ASCII. All vectors have to stem from the
same plot, otherwise a segfault may occur. Setting wr_singlescale as variable, the scale
vector will be printed only once, if scale vectors are of the same length (you have to take
care of that yourself). Setting wr_vecnames as variable, scale and data vector names are
printed on the first row. The number of significant digits is set with option numdgt.
